# Plans

One file per plan, named `YYYY-MM-DD-short-topic.md`, committed before the work starts and
kept up to date while it runs.

Each plan needs:

- **Goal**: what changes and why.
- **Steps**: the order of work, with the files and data each step touches.
- **Risks / open questions**.
- **Review**: findings from a fresh-context agent that read only the plan and the code it
  points to, and how each finding was resolved. Fill this in before acting on the plan.
- **Status**: updated as steps complete or decisions change.
